OneClickServer
==============
マイクラ / ARK(ASA・ASE) / Palworld / Terraria の
サーバーを、ボタンだけで立てられるソフトです。

使い方
  1. OneClickServer.exe をダブルクリック
  2. 「＋新しく作る」で遊びたいゲームを選ぶ
  3. 画面の案内どおりに進める

大事なこと
  - data フォルダに、設定やワールドが入っています。消さないでください。
  - 更新があると、画面に出ます。ボタンを押すだけで自動で入れ替わります(データは残ります)。
  - 以前の「OneClickServerMC」「OneClickServerARK」のデータは、ホーム画面から引き継げます。

【3.2 の変更】
  - マイクラ部分が大きく強化されました(MODを前の状態に戻す、起動前チェック、コマンド一覧、参加前チェック、ネットワーク診断 など)。
  - Discord の「サーバーが起動しました」が何度も出る不具合を直しました。

【3.1 の新機能】Discord から操作できます
  - ホーム画面の「Discord から操作する(ボット)」を開いて、5つのステップを順に進めます。
  - マイクラ・ARK・Palworld・Terraria のどれでも、Discord のボタンで「起動」「停止」「状態」ができます。
  - 起動・停止・落ちたときのお知らせが、Discord にカードで出ます。
  - ソフトとPCが動いている間だけ使えます。
