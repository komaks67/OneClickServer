# OneClickServer

マイクラ / ARK(ASA・ASE) / Palworld / Terraria のサーバーを、1つのソフトでかんたんに立てるWindows用ツール。

- Python 3.11〜3.13 + pywebview(WebView2)
- データは `data/` に保存(更新しても引き継がれる)
- ソースの置き場: `komaks67/OneClickServer`
- 配布: `OneClickServer_win.zip` と `.sha256` を GitHub Releases に置く。ソフトが更新を確認する先は `oneclick/appinfo.py` の `RELEASES_REPO`(`komaks67/OneClickServer`。このリポジトリ自身)
- 公式アイコンを使うときは `oneclick/web/icons/README.txt` を読むこと

## Discord から操作する(3.1.0〜)
- ホーム画面の「Discord から操作する(ボット)」で、5ステップの案内どおりに設定する(ボットは1つ。4ゲーム共通)
- チャンネルに「▶ 起動 / ■ 停止 / 📊 状態」のパネルを、サーバーごとに置ける。お知らせは、パネルのスレッドに「カード」で出る
- 設定は `data/minecraft/settings.json` の `discord_bot`(トークンは Windows の DPAPI で暗号化)
- コードは `oneclick/discordbot.py`(通信・カード)と `oneclick/discordhub.py`(4ゲームのつなぎ口)、画面は `oneclick/web/discord.js`

## 3.5.1 の変更
- **自動更新を直しました**: 入れ替えに6分もかかったり、黒い画面で固まって見えたりするのを直しました。入れ替えのバッチを英数字だけにして(日本語が入ると cmd が行を読みまちがえます)、「古いソフトが終わるのを待つ」方法を、1秒ごとに入れ替えを試す方式に変えました。黒い画面も出ません。
- 3.5.0 以前の版は、自動更新が遅いままです。3.5.1 だけは、zip を手で入れ替えてください(そのあとからは、数秒で更新できます)。

## 3.5.0 の変更
- **IPアドレスを、確認してから見せるように変更**: 本物のIP(自分の回線のIP・入ろうとした人のIP・BANしたIP・ログの中のIP)は、ふだん「●●●.●●●.●●●.●●●」で隠れます。「表示する」→「配信・画面共有をしていませんか？」の確認 → 見える、の順です。**30秒たつと自動でまた隠れます**。コピーも、見えているあいだだけ。
- 対象: 「友達を呼ぶ」の「IPを調べる」・ネットワーク診断・あやしいアクセス・BAN一覧・サーバーのログ(「ログのIPを表示」ボタン)・数字だけの友達用アドレス・「友達が入れないとき」の診断文
- Discord・デスクトップの通知にも、IPを書かないようにしました(IPは「あやしいアクセス」の表で確認)
- playit.gg のアドレスなど、名前のアドレスは今までどおり見えます(本物のIPではないため)

## 3.4.0 の変更
- **MODが要る Java を自動で調べる**(`oneclick/minecraft/javareq.py`): MODの中身から必要な Java を読み、マイクラの標準より新しい Java が要るMODを、MOD追加時・相性チェック・起動前チェックで知らせる
- **遊ぶ人の Java を自動で用意**: 友達用パックの「参加する」で、必要なら Java を自動でダウンロードして、そのプロファイルだけに使わせる(遊ぶ前の確認でも、足りなければ自動で直す)
- **サーバーは、MODが要る一番新しい Java で起動**(起動テストも同じ)
- **「友達が入れないとき」診断**(`oneclick/minecraft/connectdiag.py`): サーバーの状態・アドレスの古さ・外からつながるか・ホワイトリスト・バージョン・MODの Java・ログの理由を、順に調べて直し方を出す。ファイアウォール許可・「友達を呼ぶ」への移動はボタンで
- **エラーのやさしい解説**: ホワイトリスト・バージョン違い・MOD違い・ログイン失敗・重い・メモリ・ディスク・ワールド破損などを、日本語で説明。入れなかった理由は、コンソールにも「💬」で出る

## 3.3.1 の変更
- Discord の「PCの見張り」で、ディスク・CPU・メモリの警告を、**項目ごとにON/OFF**できるように(メモリの警告だけ止める、など)

## 3.3.0 の変更
- **新しい見た目(B案)**: ホーム・ゲーム画面・マイクラ画面を、明るい/ブラックの2種類のミニマルなデザインに。ゲームのアイコンは文字なし
- 「ホームへ戻る」を、右下に浮かせず、メニューの一番上に入れた(ほかの表示と被らない)
- **常駐**: 窓を閉じても、タスクトレイに残って裏で動き続ける(設定でOFF可)。Windows 起動時の自動開始も、ホームで切り替えられる(`oneclick/tray.py`、`pystray` と `pillow` を使う)
- **Discord**: ディスクの空き・CPU・メモリの警告(`oneclick/sysmon.py`。同じ警告は1時間に1回、直ったら1回だけ「もとに戻りました」)
- **Discord**: 入った・出たを、通知の連投にせず「いま遊んでいる人」の1枚のカードを書きかえる形に(ウェブフックだけの人は30秒ぶんを1通にまとめる)
- 4ゲームすべてのバックアップ画面に「最新の1つ以外を消す」ボタン

## 3.2.0 の変更

- Discord の「サーバーが起動しました」が、人の出入りのたびに何度も出る不具合を修正
- 誤字(ぶ使って → ぶつかって)を修正

## 開発
```
python -m unittest discover -s tests -v   # 自動テスト
start.bat                                  # そのまま起動
build.bat                                  # exe を作る
make_release.bat                           # 配布zip + sha256 を作る
```
版の数字は `oneclick/appinfo.py` の `VERSION`。前より大きくしないと更新として扱われません。

## 更新のしくみ
- ソフトを開いたとき、1回だけ新しい版を確認 → あれば強制更新(動作中のサーバーがある間は待つ)
- 更新前に自動バックアップ、失敗したら自動で元に戻す
- SHA-256 が無いリリースは、安全のため自動では入れない

## 確認できていないこと(Windowsの実機で要確認)
SteamCMDでの導入、各サーバーの起動/停止、Palworldのプロセス判定、Terrariaの標準入力、exe化、WebView2の表示。

## 更新の通知(通知だけ。勝手には入れません)
- ソフトを開いたとき1回、導入済みの各ゲームについて確認します。ゲームのホーム画面の「更新を確認」でも調べられます。
- ARK / Palworld: SteamCMD で、入っている版と最新の版(buildid)を比べます。
- Terraria: 公式の最新の zip 名と、入れたときの zip 名を比べます。
- ARK ASE の MOD: Steam ワークショップの更新時刻を見ます(サーバーを起動すると「見た」ことになります)。
- ARK ASA の MOD: CurseForge は API キーが要るため通知できません(起動時にゲームが自動で最新にします)。
