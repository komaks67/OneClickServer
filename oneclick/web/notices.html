ライセンスと注意事項

非公式ツールです

OneClickServer は個人が作った非公式のツールです。Minecraft(Mojang / Microsoft)、ARK(Studio Wildcard)、Palworld(Pocketpair)、Terraria(Re-Logic)、Steam(Valve)、playit.gg の各社とは関係がなく、承認も受けていません。名前・ロゴは各権利者のものです。

このソフトが外から取得するもの

  • SteamCMD(Valve): ARK・Palworld のサーバーを入れるときに、Valve の配布元から取得します。Valve の利用条件が適用されます。
  • Terraria サーバー: terraria.org の公式配布 zip を取得します。
  • Minecraft サーバー / Fabric / Forge など: 各公式の配布元から取得します。Minecraft サーバーの利用には、Minecraft の EULA への同意が必要です。
  • playit.gg エージェント(playit-cloud 製。ライセンスは配布元に従います): GitHub の公式リリースから、公表されている SHA-256 と一致したものだけを使います。playit.gg のサービスにも、独自の利用規約があります。

同梱している部品

  • pywebview(BSD-3-Clause) / psutil(BSD-3-Clause) / pythonnet(MIT) / PyInstaller(GPL-2.0 例外つき。作った exe は自由に配布できます) / Python(PSF License)

データと安全

  • 設定・ワールド・バックアップは、すべてこのソフトのフォルダの data に保存されます。あなたのデータを外部へ送ることはありません(更新の確認と、ゲーム・MOD の配布元からの取得を除く)。
  • 管理者パスワードなどは、設定ファイルに平文で保存されます。data フォルダを他の人に渡さないでください。
  • 遠隔操作用のポート(RCON / REST)は、外に開けないでください。ファイアウォールの許可は、ゲーム用のポートだけに付けます。
  • 自動更新は、配布元が公表した SHA-256 と一致したファイルだけを入れ、失敗したら元の版に戻します。

無保証です。大事なワールドは、定期的にバックアップを取ってください。
