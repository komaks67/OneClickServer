    方法1: playit.gg(おすすめ・ルーターの設定は要りません)
    
    
      
      
    1. 下の「playit を起動」を押します。黒い画面が開きます。
      2. 
      
    2. 黒い画面に出る URL をブラウザで開き、アカウントを作って「Claim」します(初回のみ)。
      3. 
      
    3. playit のサイトで、トンネルを作ります。
      4. 
      
    4. できあがった公開アドレス(例: xxxx.joinmc.link:12345)を、友達に伝えます。
      5. 
      
    5. 友達は、ゲームのダイレクト接続(IP 接続)で、そのアドレスを入れます。
      6. 
    
    
    
    
    
    サーバーを起動したまま、playit の黒い画面も開いたままにしてください。
    
    
    
      playit は、ずっと無料で使えます。
      
      
        
    • 「初回だけ」なのは、アカウント作成とトンネル作りの手順だけです。お金はかかりません。
      • 
        
    • 無料プランでは、友達が入る入口(ポート)を4つまで使えます。有料の Premium だと16個までです。
      • 
        
    • サーバー1つにつき入口を1つ使うので、無料でも4つのサーバーまで同時に公開できます。5つ以上は Premium が必要です。
      • 
        
    • サーバーごとにポート番号を変えてください。(例: A は 25565、B は 25566)
      • 
        
    • playit のサイトで、サーバーごとに別のトンネルを作り、Local Port をそれぞれのポート番号に合わせます。友達には、サーバーごとに別のアドレスを伝えます。
      • 
        
    • このソフトは playit を1つだけ起動します。同じ playit にトンネルを2つ以上作る形で使います。(2つ同時の公開は、まだ実機で確認できていません)
      • 
      
    
    
    
  
    
  
    
    
    方法2: ルーターのポート開放
    
    
      
      
    1. 下のボタンで、Windows ファイアウォールに許可を追加します(「管理者として実行」したときのみ成功します)。
      2. 
      
    2. ルーターの設定画面で、 を、このパソコンに向けて開けます。
      3. 
      
    3. 自分のグローバル IP アドレスを調べて、友達に「IPアドレス:ポート番号」で伝えます。
      4. 
    
    
    
    
    
    集合住宅の共用回線などでは、ポート開放ができないことがあります。その場合は方法1を使ってください。遠隔操作用のポートは、外に開けないでください。参加パスワードを付けると、知らない人が入るのを防げます。
